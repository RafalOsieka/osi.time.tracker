## 4. Table spacing follow-up (post-review)

Reported by the user after visually reviewing 3.3's screenshots: the mapping table's "Wpisy"/"Projekt docelowy" columns had no gap (value and select visually stuck together), and the preview table's "Zdalny projekt" column dominated width, squeezing "Projekt lokalny". Both tables previously had no cell padding at all and the preview table used browser-default `table-layout: auto`, letting the longer remote-project text dictate column widths. This revises design.md's stated non-goal ("redesigning the phase bodies... beyond relocating testids") for these two tables specifically, at the user's request.
