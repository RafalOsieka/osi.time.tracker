# Roadmap

What is planned for OSI Time Tracker. Items are grouped by area, not ordered by date; anything not listed here is not planned. Behavior that already exists is described in [`openspec/specs`](./openspec/specs/).

## Next

- **Client report:** company tax ID (NIP) and contact details.
- **Long-running timer reminder:** a notification when a timer has been running unusually long.
- **"Nothing logged today" reminder:** an optional daily nudge when no time was logged.
- **Dashboard:** charts of time per project and tracker over a period.
- **User documentation:** how to use the app.

## Browser extension

- Further UI and feature development.

## Reports

- Further expansion; direction to be decided.

## Accounts

- Self-registration.
- Password reset.
- Account deletion.
- Two-factor authentication (TOTP).
- Single sign-on (OAuth2 / OIDC).

## Later

- More tracker adapters (Jira, GitLab, …).
- PWA: installable app and push notifications.
- Email notifications.
